AUTO DIRECTOR

Script-to-clip suggestions

Local · deterministic

Matches saved descriptions, keywords, characters, location, mood, and scene text using deterministic text overlap. Scores are heuristic, not visual or AI understanding; FFmpeg thumbnails are previews only. Automatic visual descriptions of unseen footage are NOT IMPLEMENTED. Auto Create assigns only clear matches; uncertain scenes stay unassigned until confirmed.

AUDIO & CAPTIONS

Optional narration

Saved per project

Edge TTS requires internet and may be rate-limited; no paid fallback is used. Long captions wrap into two-line cards paced across the scene. Uploaded clip audio is removed; no music is mixed.

Quality options save per project. Crossfade requires voiceover and captions to be off.

Voiceover narration uses each scene's text. Longer narration extends its scene and is reported in render status.
